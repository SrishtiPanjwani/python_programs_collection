# Python Programs Collection

Beginner-friendly Python examples:

1. `factorial.py` — calculates the factorial of a non-negative integer.
2. `fibonacci.py` — prints a requested number of Fibonacci terms.
3. `structure_to_dictionary.py` — converts the attributes of a structure-like Python object into a dictionary using `vars()`.

## Requirement
Python 3

## Run
```bash
python factorial.py
python fibonacci.py
python structure_to_dictionary.py
```

Note: The structure-to-dictionary example represents structured data with a Python class.
